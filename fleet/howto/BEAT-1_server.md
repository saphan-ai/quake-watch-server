# BEAT 1 · quakewatch-server · Saphan is ready

- what this step is: the one-time setup of Saphan Studio itself, before any app
- for QuakeWatch: already done; this app was the first built on a Saphan Studio that was set up before it

## What you do

1. Install Saphan Studio and open its web console.
2. On the first start, go through the setup screens: who you are, the machines your agents may use, and the key that only you
   hold. Without that key, nothing is approved.
3. Check that Saphan answers: the console shows an empty fleet, ready for its first train.

## Why it is done once

Everything that follows is recorded and signed against this setup, so it is done once, by the owner, and not repeated for each app.
