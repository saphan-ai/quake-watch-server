# Preparation — how QuakeWatch was planned before any code

This project did not appear from nothing.
Before the first train, the advisor role planned the whole exercise on paper.
It designed the app, the four repositories and the recording protocol.
It also planned the machines and the Saphan setup.
The owner then cut the plan down to the server first.
On 2026-10-21 the owner said: "server only first but make it understandable what comes next".
The five documents below are that plan, as it was written on 2026-09-06.
Private details are blacked out (█).
